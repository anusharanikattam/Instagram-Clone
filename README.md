## ▶️ How to Run

1. Download or clone this project.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html`.
4. Install the **Live Server** extension.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. The Instagram Clone will open in your browser.

## 📸 Main Modules

### Home

Displays stories, posts, likes, comments, saves, and sharing options.

### Create Post

Allows users to upload an image, add a caption, preview the image, and publish a post.

### Explore

Displays a responsive grid of posts.

### Reels

Provides a Reels-style video/image interface.

### Profile

Displays profile information, followers, following, post count, and uploaded posts.

### Notifications

Displays likes, follows, and comments.

### Dark Mode

Allows users to switch between light and dark themes.

## 💾 Data Storage

The project uses **Browser LocalStorage** to store frontend data such as:

* Posts
* Likes
* Comments
* Saved posts
* Theme preference

No backend database is required for the current version.
